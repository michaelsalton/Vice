# Vice

Top-down game built in Unity on [Saga](Packages/com.saltbox.saga/README.md), a stylized URP pipeline that renders 3D scenes as pixel art at 480×270.

- `Assets/!Vice` holds the game: scenes, art, gameplay scripts (namespace `Vice`).
- `Packages/com.saltbox.saga` holds the rendering library (namespace `Saga.Rendering`).
